# Credits

**The Hallowed Summoner** is a student project for SWE402 (Game Development). It is not for sale or commercial distribution.

## Art and audio

All sprites, sound effects and music in this project come from **Hollow Knight** by **Team Cherry** (© Team Cherry). They are used here for educational purposes only.

| Use in the project | Source in Hollow Knight |
| --- | --- |
| The Knight: sprites, animations and sounds | The Knight |
| HUD: soul vessel and masks | HUD and inventory art |
| Arena: walls, floor, webs, lamps, mushrooms and background layers | Deepnest area art |
| Arena gate | Colosseum of Fools art |
| Menus: background, fleurs, pointers and slider handle | Main menu and pause menu art |
| Music: Deepnest, Sisters of Battle, Boss Defeat, main menu theme | Hollow Knight soundtrack by Christopher Larkin |
| Ambience and sound effects: Deepnest ambience, gate sounds, nail tink, menu click | Hollow Knight sound effects |

## Original work

All game code, editor tools, level layout and the placeholder boss were written for this project.

## Tools

Unity 6000.5.11f1, Universal Render Pipeline (2D), Input System, Cinemachine.
